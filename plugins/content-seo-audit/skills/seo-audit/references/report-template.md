# Report layout

Keep the chat version to about 15 lines. Put the full detail in the saved file.

```
## <Post title> - <stage: Day 0 / Week 2 / Week 4> check (<date>)
**Verdict:** <one sentence: OK / needs fixes / too early to judge>

**Fix these first**
1. <FAIL or WARN in plain words, where it is, how to fix>
2. ...

**Google's numbers**
- PageSpeed mobile: Performance <n>, SEO <n>, Accessibility <n>; LCP <x>s, CLS <x>
- Rich Results: <items found / errors>
- Indexing: <status>
- Search Console (week 2/4 only): <clicks> clicks, <impressions> impressions, position <n>; top query: "<q>"
- Change since last check: <up/down/same, or "first check">

**Next step:** <one thing>
```

Use plain words: say "Google can read the FAQ" instead of "FAQPage schema validates", or explain the term in a few words the first time.
